### Верхняя панель
- **Команда:** цветной кружок игрока, доктрина, пинг-индикатор связи.
- **Часы:** фаза (☀/☾), обратный отсчёт до следующей фазы; на сумерках — направление волны (С/Ю/З/В) и иконки типов зомби (если открыта «Радиовышка» или «Радиоперехват» — с числами).
- **Ресурсы:** значение + прогноз (еда — на рассвете, энергия — текущий баланс, красный при дефиците). Наведение → разбивка «откуда/куда».
- **Люди:** взрослые · дети · солдаты / вместимость жилья. Клик — выделить всех свободных мирных.
- **Мораль:** число + цвет зоны (≥70 зелёный, <30 оранжевый, <15 красный), наведение — список модификаторов.

### Алерты (слева)
Стек до 5, клик — камера к событию. Типы: укус/заражение (зелёный), атака на постройку (красный), мирные у КПП (синий), дефицит (жёлтый), исследование готово (оранжевый). Звук на каждый тип.

### Нижняя панель
- **Миникарта:** туман, свои юниты по цвету игрока, мирные — белые точки, «?» — найденные, но не спасённые; волна — красная стрелка с края; пинги союзников.
- **Выделение:** один юнит — карточка с HP, статусом (заражён/лечится), чертой (у мирных), владельцем. Несколько — сетка мини-карточек, клик сужает выбор.
- **Командная карта:** 4×3 кнопки, горячие клавиши в углу, кулдаун — радиальная заливка.

### Мировые индикаторы
- HP-полоски — только у повреждённых/выделенных.
- Иконки статуса над головой: заражён (виден после детекта), ведомый, работает, голод.
- Круг радиуса работы здания при выделении (Лесопилка 70 м), круг шума при выделении юнита (опция).
- Призрак постройки: зелёный/красный, линия до ближайшего строителя.

## 2. Экраны

| Экран | Состав |
|---|---|
| Лобби | 4 слота (ник, цвет, доктрина — карточки с описанием, «Готов»), подключение по IP/LAN, выбор карты (MVP одна), сложность (Нормально / Тяжело — ×1.3 волны) |
| Отчёт рассвета | Модальная плашка 4 с (не ставит паузу): «Ночь 4 пережита. Убито 312. Потери: 2 мирных, 1 боец. Родился 1 ребёнок. Еда −31.» |
| Дерево технологий | Граф из `tech.json`, 3 колонки по тирам, цена и время, кнопка «Исследовать» (выбор Мастерской) |
| Назначение работ | Клик по зданию → слоты работников с портретами и чертами, «+» берёт ближайшего свободного |
| Финал | Счёт по категориям, медали, график численности людей по дням |

## 3. Управление (по умолчанию)

| Действие | Клавиша |
|---|---|
| Выделить / рамка | ЛКМ / ЛКМ-тянуть |
| Добавить к выделению | Shift + ЛКМ |
| Все юниты типа на экране | двойной ЛКМ |
| Приказ (движение / атака / вход в здание / подобрать мирных) | ПКМ |
| Атака-движение | A + ЛКМ |
| Стоп / держать позицию / патруль | S / H / P |
| Способности | Q W E R |
| Группы | Ctrl+1..9 назначить, 1..9 выбрать, ×2 — камера |
| Меню стройки | B, далее буква здания |
| Камера | WASD / край экрана, колесо — зум (2 уровня наклона), СКМ — панорама |
| К базе / к событию | Home / Пробел |
| Пинг | Alt + ЛКМ (колесо пингов при удержании) |
| Скорость (только соло) | + / − / Pause |
| Все свободные мирные | . (точка) |
| Сирена | Ctrl + S (если построен громкоговоритель) |

## 4. Обратная связь, которую нельзя пропустить

- Заражение мирного внутри базы → громкий алерт + красная вспышка на миникарте.
- Начало волны → звук сирены, стрелка на краю экрана со стороны волны.
- Нет рекрутов при попытке обучить → кнопка серая + подсказка «Нет свободных взрослых».
- Дефицит энергии → иконка ⚡✕ над отключёнными зданиями.
- Крикун кричит → зелёное кольцо по земле и всплывающая иконка на миникарте.
