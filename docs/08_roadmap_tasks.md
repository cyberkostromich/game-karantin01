# Роадмап и задачи

> Задачи атомарные: одна задача = один PR = проверяемый результат. Формат ID: `M<веха>-<номер>`. Каждая веха заканчивается играбельной сборкой.

## Вехи

| Веха | Срок (соло + ИИ-агент) | Результат |
|---|---|---|
| **M0 Скелет** | 1 нед | Проект Godot, загрузка data/, камера, тестовый квартал, выделение и движение юнитов |
| **M1 Орда** | 2 нед | 1000 зомби на MultiMesh, flow-field, шум, бой пехоты, смерть/заражение |
| **M2 Лагерь** | 2 нед | Мирные, КПП, стройка, добыча, экономика, мораль, день/ночь, волны |
| **M3 Армия** | 2 нед | Все 7 юнитов, способности, техника, вертолёт, гарнизоны, тех. дерево |
| **M4 Москва** | 1.5 нед | Город из OSM, POI, гнёзда в метро, события дней, победа/поражение |

## Определение готовности MVP
- 4 игрока проходят сценарий от лобби до эвакуации без десинков и крашей.
- 60 FPS на целевом железе при ночи 10 (4 игрока).
- Новичок понимает цикл «спаси → проверь → назначь → защити» за первые 10 минут без внешних объяснений.
- Все цифры баланса — только в `data/`, `tools/balance_report.py` проходит без ошибок.
