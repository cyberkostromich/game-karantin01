# Арт-библия: КАРАНТИН: МОСКВА

> Референс-листы: `previews/sheet_*.png` · Палитра: `assets/textures/palette.png`, `previews/sheet_palette.png`

## 1. Настроение

**«Поздняя московская осень после конца света».** Серое небо, мокрый асфальт, жёлтые и красные липы, белые панельки с синими полосами, оливковая техника. Тепло только у людей — прожекторы, костры кухни, оранжевые сигнальные элементы интерфейса. Зелень заражения — единственный «неестественный» цвет в мире, и он всегда означает угрозу.

| День | Ночь |
|---|---|
| Рассеянный свет, холодно-серое небо, мягкие тени | Тёмно-синий тинт сцены (≈ #1B2A44, ×0.35 яркости), тёплые конусы прожекторов #FFE3A3, зелёные глаза и вены зомби светятся (emission) |

## 2. Стиль

- **Low-poly, flat shading**, без текстур кроме одной палитры. Детали — геометрией и цветом, не нормалями.
- **Читаемость сверху важнее реализма.** Всё должно узнаваться с высоты камеры 40–80 м: силуэт + цвет.
- Пропорции слегка «игрушечные»: головы на 10–15% крупнее реальных, оружие толще — иначе пропадает на экране.
- Никаких реальных логотипов и брендов (вывески — цветные полосы без текста, метро — красный знак без «М»).

## 3. Цветовые правила

| Роль | Цвета палитры | Правило |
|---|---|---|
| Военные | `OLIVE_D/OLIVE/OLIVE_L`, `HELMET`, `KHAKI`, `CAMO_BROWN` | Тело юнита всегда оливковое/хаки — отличает от мирных |
| Цвет команды | ячейка `TEAM` (в текстуре #2F80ED) | Повязка, флажок, тактический знак. **Шейдер заменяет цвет ячейки на цвет игрока**: синий #2F80ED, оранжевый #F2994A, бирюзовый #27AE9F, жёлтый #F2C94C |
| Мирные | `CIV_*` насыщенные | Яркая одежда — видно, кого спасать |
| Зомби | `ZMB_SKIN/_D`, `ZMB_CLOTH/_D`, `BLOOD`, `INFECT_GLOW` | Приглушённые, грязные. Глаза — `INFECT_GLOW` с emission |
| Заражённый мирный (инкубация) | — | Шейдер: lerp к `INFECT_GLOW` 0→25% за последние 10 с + лёгкое покачивание |
| Город | `PANEL_*`, `BRICK*`, `STALIN_YEL`, `CONCRETE*`, `ASPHALT` | Нейтральный фон, не спорит с юнитами |
| Природа | `LEAF_AUTUMN`, `LEAF_RED`, `LEAF`, `BIRCH`, `PINE` | Осень: 60% жёлтое/красное, 40% зелёное |
| Интерфейс | `SIGNAL_ORANGE` #FF6A1F, графит #2E333B | Оранжевый = действие/внимание, красный = опасность, зелёный = заражение |

## 4. Масштаб, оси, пивоты

- 1 ед. = 1 м. Человек 1.8 м, ребёнок 1.25 м, громила 2.2 м, великан 3.7 м.
- Y вверх, модель смотрит в **+Z**, pivot — центр основания на земле (y = 0).
- Здания вписаны в footprint из `data/buildings.json` (клетка 2 м): `bld_house` = 4×6 клеток = 8×12 м.
- Стены, мешки, ворота — модульные, длина сегмента 4 м (стена, мешки) и 6 м (ворота), стыкуются по X.

## 5. Именование и узлы

```
<категория>_<имя>[_<вариант>].glb
unit_assault  unit_sniper  unit_medic  unit_scout
civ_adult_a…e  civ_child  civ_worker_carry
zmb_walker  zmb_walker_armored  zmb_runner  zmb_brute  zmb_screamer  zmb_spitter  zmb_giant  zmb_nest
veh_bmp  veh_tank  veh_heli
bld_<id из buildings.json>
city_<тип>   prop_<тип>   pickup_<ресурс>
```

**Обязательные узлы** (финальные модели должны их сохранить — код ищет по имени):

| Тип | Узлы | Пивот |
|---|---|---|
| Гуманоиды | `body`, `head`, `arm_l`, `arm_r`, `leg_l`, `leg_r`, `weapon` (опц.); с v3 — дочерние `forearm_l/r` (в `arm_*`) и `shin_l/r` (в `leg_*`) | плечо / бедро / шея; локоть / колено |
| БМП, танк | `hull`, `turret`, `barrel` | центр погона башни / цапфа ствола |
| Вертолёт | `body`, `rotor_main`, `rotor_tail` | ось винта |
| Ворота | `door_l`, `door_r` | петля |
| КПП | `barrier` | ось шлагбаума |
| Прожектор / сирена | `lamp` / `speakers` | точка крепления |
| Металлоразборка | `crane_arm` | ось крана |
| Гнездо | `body`, `pulse` (пульсирует scale) | центр |

В финале гуманоидам нужен скелет (рекомендуется совместимый с Mixamo / Quaternius), но модели с узлами позволяют процедурную анимацию уже в прототипе: v3 — ходьба/бег со сгибом колен и локтей, покой (дыхание, осмотр), работа, тренировка, паника, отдача, шатание заражённого, падение при смерти (`src/view/HumanAnim.gd`); орда — то же вершинным шейдером по индексу части в UV2 (`zombie.gdshader`: шаг, выпад и удары в атаке, присед над добычей).

**Персонажи v4 (D-11): Kenney «Animated Characters» (CC0).** Тела бойцов, мирных и зомби — одна модель Kenney (1604 треугольника, скелет; `tools/asset_gen/kenney/`, License.txt) со скинами-текстурами. Blender (`bl_kenney.py`) ставит скелет в позу (повороты костей + двухзвенная IK запястий для хвата оружия), «раздувает» громилу/великана по весам костей и режет меш по костям на жёсткие узлы игры — поэтому процедурная анимация и MultiMesh орды работают без скиннинга. Чего у Kenney нет, сделано по тем же правилам: форма «цифра», хаки, маскхалат, грязная форма заражённого — перекраска областей UV исходных скинов (`kenney.py`); шлемы и головные уборы — оболочка по поверхности головы (ничего не просвечивает), бронежилеты, рюкзаки, оружие — палитровые детали с фаской. Скины рисуются шейдером `palette_skin` / `zombie_skin` (тело палитрового: тинт заражения, подсветка), остальное — палитра. Отступление от «одного материала палитры» — у персонажей два: палитра + скин. Кеш Blender — `tools/asset_gen/.cache/kenney.json.gz` и `bl_pieces.json.gz` (в git); стенд в движке: `godot res://tools/dev/anim_viewer.tscn -- --out=/tmp/anim`, снимок — `previews/sheet_characters_ingame.png`.

## 10. Как заменить плейсхолдеры финальными моделями

1. Сохранить имя файла и имена узлов (§5).
2. Сохранить габариты в пределах ±10% (коллизии и footprint завязаны на них).
3. Использовать `palette.png` или собственный атлас с тем же материалом `palette` — тогда не придётся трогать код.
4. Прогнать `tools/balance_report.py` — он проверит, что все модели и иконки из `data/` на месте.

**Источники бесплатных ассетов для ускорения** (CC0 — без указания авторства, но лицензию каждой паки проверять на странице):
- Kenney — City Kit (Commercial / Suburban / Industrial) — пропсы, дороги, машины.
- Quaternius — low-poly персонажи, монстры, природа (в т.ч. анимированные).
- Mixamo (Adobe) — бесплатные анимации гуманоидов для риггованных моделей (не CC0, но разрешено использование в играх; проверить условия).
- Poly Pizza — каталог low-poly моделей с разными лицензиями (фильтровать CC0).
